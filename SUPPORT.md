# Support

- SDK, MCP, API contract, or example bugs: [GitHub issues](https://github.com/heossihq/bee-public/issues)
- Product, account, and billing support: [Bee contact](https://bee.heossi.com/contact?category=support)
- Security disclosures: `bee-security@heossi.com`
- Service availability: [bee.heossi.com/status](https://bee.heossi.com/status)

When reporting a developer defect, include package version, runtime version, operating system, a minimal reproduction, expected behavior, actual behavior, and a redacted error trace.

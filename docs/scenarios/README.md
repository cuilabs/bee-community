# Enterprise integration scenarios

These public scenarios show how Bee's architectural controls compose for common
customer workflows. They describe boundaries and evidence, not an assurance or
certification beyond the material linked from the
[Bee enterprise centre](https://bee.heossi.com/enterprise).

| Scenario | Primary boundary | Detailed flow |
| --- | --- | --- |
| Governed coding in an IDE | Local workspace effects remain approval-gated | [Bee Code](./bee-code.md) |
| Tenant-scoped retrieval | Documents and citations remain tenant-scoped | [Knowledge retrieval](./tenant-rag.md) |
| Explicit quantum reasoning | Hardware submission is separate and entitled | [Quantum Reasoning Lab](./quantum-reasoning.md) |

For the shared system layers, see the [public reference architecture](../architecture.md).
